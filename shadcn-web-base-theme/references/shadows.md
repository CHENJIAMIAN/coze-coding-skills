# 阴影参数详细说明

使用 `--shadow <shadow_style>` 参数指定。

## tool

- **关键词**：标准、实用、通用、Tailwind、清晰、层级
- **描述**：标准的实用主义阴影，基于 Tailwind 默认配置。提供清晰的层级感，适用于大多数通用场景。
- **适用场景**：管理后台、工具类应用、SaaS 平台。

## artistic

- **关键词**：微妙、精致、轻盈、艺术、画廊、留白
- **描述**：非常微妙且精致的阴影，色调偏淡。旨在不干扰内容的前提下提供极轻的悬浮感，适合展示图片或艺术作品。
- **适用场景**：作品集、画廊、设计类网站。

## bento

- **关键词**：现代、卡片、网格、Apple 风格、清晰、聚焦
- **描述**：专为 Bento Grid（便当盒布局）优化的阴影。强调卡片之间的分离度，现代感强，适合高密度的信息展示。
- **适用场景**：个人主页、仪表盘、现代落地页。

## cool

- **关键词**：冷调、科技、理智、蓝色调、现代、清爽
- **描述**：带有冷色（蓝色/青色）倾向的阴影。传递科技感与理智，比纯黑阴影更具现代气息。
- **适用场景**：科技产品、SaaS、数据分析工具。

## retro

- **关键词**：复古、硬朗、 distinct、怀旧、纸质、手工
- **描述**：可能带有更硬的边缘或特定的色调，模仿旧式打印或纸质效果。传递怀旧与手工感。
- **适用场景**：复古品牌、生活方式博客、独立游戏。

## superbase

- **关键词**：开发者、开源、专业、绿色调、极客、高效
- **描述**：参考 Supabase 风格，可能带有特定品牌色（如微弱的绿色）的阴影。传递开发者友好的专业感。
- **适用场景**：开发者工具、文档站、开源项目。

## tech

- **关键词**：锐利、未来、赛博、高对比、发光、硬核
- **描述**：锐利或带有发光感的阴影。强调科技属性与未来感，适合暗黑模式或高科技风格。
- **适用场景**：Web3、区块链、电竞、未来风格应用。

## vintage

- **关键词**：温暖、柔和、岁月、褐色调、舒适、阅读
- **描述**：带有暖色（褐色/黄色）倾向的阴影。传递岁月的沉淀与温暖舒适的阅读体验。
- **适用场景**：书店、咖啡馆官网、长文阅读平台。

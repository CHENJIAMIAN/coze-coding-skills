# 字体参数详细说明

使用 `--fonts <font_style>` 参数指定。

## business

- **关键词**：干净、现代、专业、效率、秩序、逻辑、理性、B2B、金融、科技
- **描述**：干净利落的线条，传递高效、现代与专业的企业形象。无多余装饰，专注于信息传递。
- **行业与心理**：适合 B2B 平台、SaaS 工具、金融分析。心理上给人以可靠、有条理和值得信赖的感觉。
- **推荐搭配**：`none`, `xs`, `sm` 或 `md` 圆角。

## classic

- **关键词**：传统、优雅、易读、沉稳、权威、学术、文学、出版、教育、历史
- **描述**：带有衬线或经典比例，传递传统、优雅与易读的阅读体验。如同纸质书般的质感。
- **行业与心理**：适合在线出版、教育平台、奢侈品官网。心理上暗示权威、深思熟虑和高贵。
- **推荐搭配**：`sm` 或 `md` 圆角。

## playful

- **关键词**：友好、亲近、创意、活泼、快乐、年轻、社交、游戏、休闲、个性
- **描述**：圆润或手写风格，传递友好、亲近与充满创意的氛围。打破僵硬，拉近距离。
- **行业与心理**：适合社交应用、创意作品集、青年生活方式品牌。心理上带来轻松、愉快和开放的心态。
- **推荐搭配**：`lg`, `xl` 或 `2xl` 圆角。

# Audio Skill

This skill guides the implementation of audio functionality using the `coze-coding-dev-sdk` package and CLI tool, enabling both text-to-speech synthesis (TTS) and speech-to-text recognition (ASR) capabilities.

## Overview

Audio capabilities allow you to build applications with speech synthesis (TTS) and speech recognition (ASR), enabling voice assistants, audio content generation, transcription services, and voice-enabled user interfaces.

## Supported Languages

This skill supports both Python and TypeScript SDKs. Choose the appropriate version for your project. **You MUST refer to the detailed guide in the corresponding SDK folder.**

- **Python SDK**: See [python/README.md](python/README.md) for installation, client initialization, and usage examples.
- **TypeScript SDK**: See [typescript/README.md](typescript/README.md) for installation, client initialization, and usage examples.

# Database 技能

本技能指导如何使用 `coze-coding-dev-sdk` 包实现 PostgreSQL 数据库功能，支持结构化数据的存储、检索和管理。Database 技能允许您使用 PostgreSQL 管理结构化数据。它提供了一套统一的工作流，用于定义 Schema (ORM)、管理迁移以及实现类型安全的 CRUD 操作。

## 支持的语言

本技能同时支持 Python 和 TypeScript SDK。请根据您的项目选择合适的版本。 **您必须要参考对应的 SDK 文件夹中的详细指南。**

- **Python SDK**: 安装、客户端初始化和使用示例请参阅 [python/README.md](python/README.md)。
- **TypeScript SDK**: 安装、客户端初始化和使用示例请参阅 [typescript/README.md](typescript/README.md)。
